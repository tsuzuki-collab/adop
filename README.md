# 提案企画書 自動作成エージェント｜デモ

株式会社アドップ様への商談用デモ。ブラウザ上で「ヒアリング取り込み → 案件カルテ抽出 → 企画書ドラフト生成 → ヒアリング不足の指摘 → 過去案件の検索」までを一通り操作できます。

**表示されるデータはすべてサンプルです。** APIキーもサーバー処理も使いません。静的ファイルのみで動きます。

---

## GitHub → Vercel でのデプロイ手順

1. GitHubで新しいリポジトリを作成（Public / Private どちらでも可）
2. この3ファイルをリポジトリの**直下**にアップロード（Add file → Upload files → Commit）
3. [vercel.com](https://vercel.com) にGitHubアカウントでログイン
4. **Add New → Project** → 作成したリポジトリを **Import**
5. 設定画面はそのままでOK（Framework Preset は `Other`、Build Command と Output Directory は空欄のまま）
6. **Deploy** を押す。30秒ほどで `https://<プロジェクト名>.vercel.app` が発行されます

以降、GitHubにコミットすると自動で再デプロイされます。

## 商談での操作の流れ

| 手順 | 操作 | 話すこと |
|---|---|---|
| 1 | 文字起こしの内容を見せる | 「商談の録音をそのまま入れています」 |
| 2 | 「ドラフトを生成する」を押す | 進行中の4ステップを指しながら待つ（約8秒） |
| 3 | **案件カルテ**タブ | 「出典の列を見てください。全部どの発言から取ったか残ります」 |
| 4 | **企画書ドラフト**タブ | 章を切り替えて本文が生成される様子を見せる |
| 5 | **ヒアリング充足チェック**タブ | 「ここが他のツールとの違いです」 |
| 6 | **スライドプレビュー**タブ | サムネイルをクリックで拡大。←→キーでめくれます |
| 7 | **案件カルテ一覧**タブ | 検索欄に文字を打つと絞り込みが動きます |

検索欄はその場で自由に打ち替えられます。「アパレル」「法人」なども入れてみてください。

## 見せる前の確認

- 生成ボタンを押してから結果表示まで約8秒。この間に何を話すか決めておく
- 検索欄・文字起こし欄は先方に触ってもらえます。触ってもらうと一気に自分ごとになります
- 「入力を変えても出力は固定です」と聞かれたら、正直にデモ環境であると答えて問題ありません。ここで嘘をつくと後の信頼を失います
- スライドはあえてデザイン未仕上げの状態にしています。「骨格まではAI、仕上げは制作チーム」という線引きを口頭で必ず添えてください

## カスタマイズ

`index.html` の上部にあるデータ定義を書き換えれば、内容を差し替えられます。

| 定数 | 内容 |
|---|---|
| `TRANSCRIPT` | 文字起こしの初期テキスト |
| `KARTE` | 案件カルテの抽出項目（末尾の `1` は未取得＝赤表示） |
| `SECTIONS` | 企画書ドラフトの章と本文（`【】` で囲むとハイライト） |
| `GAPS` | ヒアリング不足の項目と推奨質問 |
| `SLIDES` | スライドプレビューの各ページ（type別にレイアウトが切り替わります） |
| `PAST` | 案件カルテ一覧のダミー過去案件 |
| `GSTEPS` | 生成中に表示するステップと待ち時間（ミリ秒） |
